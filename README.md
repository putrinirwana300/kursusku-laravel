# KursusKu (Laravel)

Project praktikum Pemrograman Web III (PHP & MySQL).

## Requirement
- PHP 8.2 atau lebih baru
- Composer
- Laravel
- XAMPP / Laragon

## Cara Menjalankan
1. Buka terminal pada folder project.
2. Jalankan: `composer install`
3. Salin `.env.example` menjadi `.env` (jika belum ada).
4. Jalankan: `php artisan key:generate`
5. Jalankan: `php artisan serve`
6. Buka alamat: http://127.0.0.1:8000

## Fitur Milestone 7
- Named route `home`
- `HomeController@index`
- Blade landing page (`home.blade.php`)
- Data kursus dari controller
- Asset CSS dan gambar terintegrasi
